# AppScope moth scout — concept v1

Generated with the built-in image generation tool. Original raster mascot concept; not a vector master.

## Prompt

Create a polished original mascot logo for AppScope, an open-source Mac MCP tool that helps AI agents discover app keyword rankings and competitors. A single charming moth scout, front facing, compact symmetrical wing silhouette, two large observant binocular-like eyes integrated naturally into its face, tiny antennae, subtle friendly smile. Clever and curious, appealing to independent developers, not childish. Bold clean vector-style flat shapes, midnight navy outlines/body, mint green wings with restrained cream accents. Wing negative space subtly suggests an upward step without literal charts. Strong recognizable silhouette at small size, restrained detail, crisp professional identity design. Single standalone mascot mark centered with generous margins on a genuinely transparent background. No text, no wordmark, no gradients, no mockup, no decorative scenery, no extra characters, no watermark. Square high-resolution composition.
